# Sudoku MNIST Multi-task Model

This project features a multi-task learning architecture based on a custom `SudokuMNIST` dataset. The goal is to simultaneously predict several properties of a 3x3 grid composed of 9 randomly sampled MNIST digits.

## Dataset

The `SudokuMNIST` dataset is generated by sampling 9 distinct MNIST digits without replacement. The 10th digit is considered the "missing" digit. The 9 selected digits are arranged into a $3 \times 3$ grid. The dataset labels include:
1.  **Missing Digit**: A single scalar label `[0-9]` representing the 10th digit not present in the 3x3 grid.
2.  **Sort Order**: A categorical label for each row and column determining if the digits are arranged in ascending (1), descending (2), or unordered (0) sequence.
3.  **Normalized Sum**: A scalar value for each row and column representing the sum of the digits, normalized to the range `[0, 1]`.

## Architecture

The `SudokuMNISTModel` is a custom Convolutional Neural Network built upon a compact backbone of `BottleneckBlock`s to extract shared representations. The model has under 20,000 parameters and branches into three specialized heads:

1.  **Missing Digit Head**: An Adaptive Average Pooling layer followed by a linear classifier to output logits for the 10 classes `[0-9]`.
2.  **Ordering Head**: Specialized spatial pooling operations `AdaptiveAvgPool2d((3, 1))` and `AdaptiveAvgPool2d((1, 3))` extract row and column features. These are passed to a linear layer, producing logits for the 3 ordering classes for each of the 6 sequences (3 rows, 3 columns).
3.  **Sum Head**: Utilizing the same spatial features as the ordering head, this branch uses an MLP ending with a `Sigmoid` activation to predict the normalized sum for the 6 sequences.

## Training Details

The network is trained using a composite loss function:
$$\mathcal{L} = \mathcal{L}_{\text{missing}} + 2 \cdot \mathcal{L}_{\text{sort}} + \mathcal{L}_{\text{sum}}$$
Where:
-   $\mathcal{L}_{\text{missing}}$ is the CrossEntropy loss for the missing digit classification.
-   $\mathcal{L}_{\text{sort}}$ is the CrossEntropy loss for the sort order classification.
-   $\mathcal{L}_{\text{sum}}$ is the Mean Squared Error (MSE) loss for the normalized sum prediction.

The `train.py` script splits the dataset into Training (50,000), Validation (10,000), and Test (20,000) subsets. The `Adam` optimizer is used.
